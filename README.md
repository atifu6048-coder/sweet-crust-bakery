# 🎂 Sweet Crust Bakery

> **Fresh, Homemade Delights Baked Just For You**  
> Sweet Crust Bakery is a boutique home bakery located in **Mardan, Pakistan**, specializing in handcrafted celebration cakes, cupcakes, brownies, and tea cookies made fresh to order with pure butter and real ingredients.

---

## ✨ Features & Highlights

- **5 Complete Routes:**
  - **Home (`/`)**: Hero banner, Why Choose Us values, customer-favorite best sellers, custom cake callout, and local reviews.
  - **Menu (`/menu`)**: Interactive category filtering across celebration cakes and sweet treats with exact pricing and instant WhatsApp order prefill.
  - **About (`/about`)**: The story of our home kitchen in Mardan, our 3 core values (*Fresh Always*, *Honest Prices*, *Made with Love*), and ingredient pledges.
  - **Gallery (`/gallery`)**: Visual showcase of baked creations with category filtering and design inquiry links.
  - **Contact (`/contact`)**: Verified bakery address, operating hours, direct phone line (`0300 1234567`), email, and an order inquiry form with validation.

- **Direct WhatsApp Ordering:**
  - One-click ordering buttons targeting `+92 300 1234567` (`https://wa.me/923001234567`).
  - Automatically encodes the exact product name into the message for rapid customer fulfillment.

- **Honest Form Validation:**
  - Client-side validation ensuring Name, Phone, and Message fields are properly supplied without pretending to dispatch automated backend emails. Provides immediate handoff to WhatsApp with customer details prefilled.

- **Signature Aesthetic & Brand Identity:**
  - Palette: Cream (`#FFF8F0`), Bakery Brown (`#6B4226`), Warm Peach (`#E07856`), Soft Pink (`#FBE3D9`), Dark Cocoa (`#2E211A`).
  - Modern typography using **Google Poppins**.
  - Accessible contrast, clear focus states, and responsive navigation on mobile, tablet, and desktop.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.17+ or v20+)
- npm

### Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/atifu6048-coder/sweet-crust-bakery.git
cd sweet-crust-bakery
npm install
```

### Development Server
Run the local development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
Create an optimized production build:
```bash
npm run build
npm run start
```

### Linting & Type Checking
```bash
npm run lint
npx tsc --noEmit
```
